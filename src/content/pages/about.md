你好，我是 **ShiningBlack**，一名热衷于系统工程、桌面软件与全栈开发的程序员。

### 关于这个博客

这个站点是我用来沉淀技术笔记、工程踩坑记录和日常思考的地方，整体采用「**零维护成本**」架构设计：

- **静态驱动**：基于 [Astro](https://astro.build) + Tailwind CSS 构建，全站静态 HTML 部署在 Vercel Edge CDN，打开速度极快。
- **Git-CMS 后台**：集成 [Sveltia CMS](/admin)，在浏览器即可可视化撰写 Markdown 文章与上传图片，保存后自动提交至 GitHub 并触发构建。
- **零库评论**：使用基于 GitHub Discussions 的 [Giscus](https://giscus.app) 评论系统，无需自建后端或维护数据库。
- **离线搜索**：通过 Pagefind 在构建期生成静态搜索索引，按下 `Ctrl / Cmd + K` 即可即时检索全站文章。
